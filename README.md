# Sai Vinaya Manaswi Seeda - Portfolio

Personal portfolio built with Next.js and prepared for deployment through GitHub and Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy through GitHub and Vercel

1. Create a new empty repository on GitHub.
2. Upload all files from this project to the repository root and commit them.
3. Sign in to Vercel and choose **Add New > Project**.
4. Import the GitHub repository.
5. Confirm **Framework Preset: Next.js** and click **Deploy**.

No environment variables are required.

## Production check

```bash
npm run build
```
